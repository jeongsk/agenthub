# Jenkins

Jenkins는 오래된 CI 서버의 표준에 가까운 자동화 플랫폼입니다. 자체 호스팅 빌드, 테스트, 배포 파이프라인을 안정적으로 운영하고 싶을 때 여전히 많이 쓰입니다.

## 언제 쓰나

- 자체 호스팅 CI/CD 파이프라인이 필요할 때
- 플러그인 기반으로 빌드·배포 자동화를 세밀하게 제어하고 싶을 때
- 레거시부터 현대적인 파이프라인까지 함께 운영해야 할 때
- 웹 UI 중심으로 작업 상태와 잡을 관리하고 싶을 때

## 핵심 특징

- 파이프라인과 잡을 웹 UI로 관리합니다.
- 플러그인 생태계가 매우 큽니다.
- Groovy 기반 파이프라인을 지원합니다.
- 대규모 자동화 허브로 오래 검증된 프로젝트입니다.
