# Pipecat

Pipecat은 실시간 음성·멀티모달 대화 에이전트를 만드는 Python 프레임워크입니다. 스트리밍 오디오와 대화 파이프라인을 조합해 사용할 수 있습니다.

## 언제 쓰나

- 음성 비서, 상담 봇, 코치형 에이전트를 만들 때
- 스트리밍 TTS / STT / 대화 파이프라인이 필요할 때
- 멀티모달 입력과 출력이 섞인 실시간 경험을 설계할 때
- 여러 에이전트나 서비스가 협업하는 파이프라인을 구성할 때

## 특징

- 실시간 처리와 낮은 지연을 염두에 둔 구조입니다.
- 대화 파이프라인을 모듈 방식으로 조합할 수 있습니다.
- Pipecat Subagents, Flows, CLI, Debugger 같은 주변 생태계도 큽니다.
- Claude Code용 Skills도 제공해서, 에이전트 워크플로와의 연결성이 좋습니다.
