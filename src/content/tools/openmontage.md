# OpenMontage

OpenMontage는 세계 최초의 오픈소스 에이전틱 비디오 제작 시스템입니다. AI 코딩 어시스턴트(Claude Code, Codex, Cursor 등)를 완전한 비디오 제작 스튜디오로 전환합니다. 자연어로 설명하면 에이전트가 리서치, 스크립팅, 에셋 생성, 편집, 최종 컴포지션까지 처리합니다.

## 언제 쓰나

- 코딩 에이전트로 비디오 제작 워크플로를 실행하고 싶을 때
- 스톡 푸티지와 오픈 아카이브에서 실제 모션 클립을 검색해 편집할 때 (단순 이미지 애니메이션 X)
- 리서치·스크립트·에셋 생성·편집·렌더링까지를 한 파이프라인으로 묶고 싶을 때
- Flux, Stable Diffusion, Remotion 등과 통합된 제작 환경이 필요할 때

## 핵심 특징

- 12개 파이프라인, 52개 도구, 500개 이상의 에이전트 스킬.
- 스톡 푸티지와 오픈 아카이브 기반 실제 모션 클립 작업.
- Flux, Stable Diffusion, Remotion, ElevenLabs 등 연동.
- AGPL-3.0 오픈소스로 완전 공개.
