# Claude SEO

Claude SEO는 Claude Code 안에서 SEO 분석과 개선 작업을 돕는 스킬입니다. 기술 SEO, 콘텐츠 품질, 구조화 데이터, AI 검색 최적화, 로컬 SEO, 국제 SEO를 여러 서브스킬과 에이전트로 나눠 점검해 주기 때문에, 사이트를 진단하고 우선순위가 있는 실행 계획을 얻고 싶을 때 유용합니다.

## 언제 쓰나

- 사이트의 기술 SEO 상태를 빠르게 점검하고 싶을 때
- 스키마 마크업, E-E-A-T, 콘텐츠 품질을 함께 검토하고 싶을 때
- GEO/AEO 같은 AI 검색 최적화 관점까지 같이 보고 싶을 때
- 로컬 SEO, 백링크, 국제화 SEO를 한 번에 묶어 분석하고 싶을 때
- Claude Code 안에서 병렬 서브에이전트 기반 SEO 워크플로를 쓰고 싶을 때

## 핵심 특징

- **25개 서브스킬 + 18개 전문 에이전트**로 분석을 나눠 처리합니다.
- **기술 SEO, E-E-A-T, 스키마, GEO/AEO**를 하나의 워크플로로 묶습니다.
- **Google 원천 가이드 기반**의 근거 중심 추천을 지향합니다.
- **PDF/Excel 보고서**와 다양한 확장 기능을 지원합니다.
- **Claude Code 플러그인 형태**로 설치해 바로 사용할 수 있습니다.
