# Claude Code Haha

`Claude Code Haha`는 Claude Code를 중심으로 한 크로스플랫폼 데스크톱 작업대입니다. 터미널 안에 오래 머무르기보다, 세션·프로젝트·브랜치/워크트리·코드 Diff·승인 흐름을 한 화면에서 관리하고 싶을 때 적합합니다. macOS, Windows, Linux용 앱과 CLI 실행 경로를 함께 제공합니다.

## 언제 쓰나

- Claude Code 작업을 데스크톱 앱으로 정리해서 보고 싶을 때
- 여러 프로젝트와 세션을 전환하면서 작업해야 할 때
- 브랜치나 Worktree를 분리해서 안전하게 실험하고 싶을 때
- 오른쪽 패널에서 변경 파일과 Diff를 바로 확인하고 싶을 때
- 위험한 명령이나 도구 호출을 승인 기반으로 다루고 싶을 때
- Computer Use, 원격 H5 접속, IM 연동, 예약 작업까지 한 곳에 모으고 싶을 때

## 핵심 특징

- **데스크톱 워크벤치**: 회의실처럼 분리된 프로젝트/세션 UI를 제공합니다.
- **브랜치 / Worktree 실행**: 새 세션을 기존 작업 트리 또는 격리된 Worktree로 시작할 수 있습니다.
- **코드 Diff와 편집 상태 확인**: 변경 파일, 증감 라인, 편집 과정을 바로 볼 수 있습니다.
- **승인 중심 흐름**: 위험 명령과 도구 호출을 앱 안에서 확인하고 처리할 수 있습니다.
- **멀티 모델 제공자 지원**: Anthropic 호환 API와 일부 대체 모델 구성을 함께 다룹니다.
- **Computer Use 및 원격 접속**: 화면 조작과 H5 원격 접속 기능을 지원합니다.
- **IM 연동과 예약 작업**: Telegram 등 메신저 연동과 정기 작업 관리가 포함됩니다.
