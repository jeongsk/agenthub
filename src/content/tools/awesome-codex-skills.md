# Awesome Codex Skills

Awesome Codex Skills는 Codex CLI와 API에서 쓸 수 있는 공개 스킬을 한곳에 모아 둔 큐레이션 저장소입니다. 반복 업무를 Codex로 넘기고 싶을 때, 어떤 스킬이 있는지 빠르게 훑어보기 좋습니다.

## 언제 쓰나

- Codex에서 바로 쓸 만한 공개 스킬을 찾고 싶을 때
- 반복되는 업무를 스킬로 정리해 자동화하고 싶을 때
- Codex용 `SKILL.md` 작성 예시와 구조를 참고하고 싶을 때
- 여러 실전 스킬을 한 번에 비교해 보고 싶을 때

## 특징

- Codex CLI와 API를 기준으로 한 스킬 큐레이션
- 개발, 생산성, 커뮤니케이션, 데이터, 유틸리티 등 다양한 범주 포함
- 각 스킬의 설치 경로와 활용 맥락을 함께 제공
- 실무 자동화용 예시를 빠르게 탐색하기 좋음
