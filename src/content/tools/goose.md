# goose

goose는 로컬에서 실행하는 오픈소스 AI 에이전트입니다. 데스크톱 앱, CLI, API를 함께 제공해 코드 작업, 워크플로 자동화, 연구 같은 작업을 한곳에서 다룰 수 있습니다.

## 언제 쓰나

- 데스크톱 앱과 CLI를 함께 쓰는 로컬 에이전트 환경이 필요할 때
- 코드뿐 아니라 문서, 자동화, 데이터 작업까지 에이전트로 처리하고 싶을 때
- 여러 모델 공급자를 바꿔 쓰면서 하나의 에이전트 런타임을 유지하고 싶을 때
- 확장 가능한 오픈소스 에이전트 플랫폼을 찾고 있을 때

## 특징

- macOS, Linux, Windows용 데스크톱 앱을 제공합니다.
- CLI와 API로도 사용할 수 있습니다.
- 여러 모델 공급자와 ACP/MCP 확장을 지원합니다.
- 프로젝트별 커스텀 배포와 확장 구성이 가능합니다.

- 이 저장소는 단일 유틸리티보다 **범용 AI 에이전트 하네스**에 가깝습니다.
