# Immersive Translate

Immersive Translate는 웹 리서치와 다국어 자료 읽기를 수월하게 만드는 번역 확장입니다.

## 핵심 용도

- 웹페이지 번역
- PDF와 자막 번역
- 입력창 보조 번역
- 다국어 자료 조사
