# Claude Obsidian

Claude Obsidian은 Claude Code와 Obsidian을 연결하는 지식 동반자입니다. Karpathy의 LLM Wiki 패턴을 기반으로 영속적인 위키 저장소를 운영하며, Claude Code의 슬래시 명령어(/wiki, /save, /autoresearch)로 지식을 축적하고 검색합니다.

## 언제 쓰나

- Claude Code가 작업 중 얻은 지식을 Obsidian에 자동 저장하게 하고 싶을 때
- 이전 세션의 지식을 다음 세션에서도 활용하고 싶을 때 (영속적 위키)
- 자율 연구(autoresearch)를 통해 지식 베이스를 스스로 확장하게 하고 싶을 때
- Obsidian을 AI 에이전트의 세컨드 브레인으로 활용하고 싶을 때

## 특징

- Claude Code 슬래시 명령어 (/wiki, /save, /autoresearch) 지원
- Karpathy LLM Wiki 패턴 기반 영속적 위키
- 자율 연구(autoresearch)로 지식 자동 확장
- Obsidian 볼트와 직접 연동
- 다중 에이전트 지원
- RAG 기반 지식 검색
