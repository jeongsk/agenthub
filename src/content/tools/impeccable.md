# Impeccable

Impeccable은 AI가 흔한 SaaS 템플릿에서 벗어나 더 나은 디자인 결정을 내리도록 돕는 디자인 스킬 세트입니다. 프론트엔드 스타일, 타이포그래피, 공간감, 상호작용 규칙을 정리해 UI 품질을 끌어올리고 싶을 때 적합합니다.

## 언제 쓰나

- AI가 만든 화면이 너무 평범하거나 비슷비슷할 때
- 프론트엔드 디자인 기준과 금지 패턴을 명확히 하고 싶을 때
- 브라우저 확장과 CLI를 함께 써서 디자인 피드백을 반복하고 싶을 때
- 팀이나 에이전트에게 일관된 디자인 언어를 주고 싶을 때

## 핵심 특징

- 23개 명령과 여러 기준 파일로 디자인 언어를 제공합니다.
- 결정론적 규칙과 LLM 비평 단계를 함께 사용합니다.
- CLI와 브라우저 확장 모두를 지원합니다.
- 사이트에서 바로 번들 형태로 내려받아 쓸 수 있습니다.
