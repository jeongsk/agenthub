# Agent Skills

Agent Skills는 AI 코딩 에이전트가 실제 팀처럼 일하도록 돕는 생산용 스킬 모음입니다. 설계, 구현, 테스트, 리뷰, 배포처럼 반복되는 개발 절차를 표준화해서, 에이전트가 매번 같은 품질 게이트를 지나가게 만들고 싶을 때 유용합니다.

## 언제 쓰나

- Claude Code나 유사 에이전트에 검증된 개발 절차를 붙이고 싶을 때
- 코드 작성과 테스트, 리뷰, 배포를 한 흐름으로 묶고 싶을 때
- 사람 팀의 엔지니어링 규칙을 에이전트에게 재사용 가능한 스킬로 넘기고 싶을 때
- 프로젝트별로 정해진 개발 체크리스트를 여러 에이전트에서 공유하고 싶을 때

## 핵심 특징

- 품질 게이트와 워크플로를 스킬로 패키징합니다.
- 설계부터 배포까지 개발 전 단계를 지원합니다.
- Claude Code, Cursor, Gemini, Codex 계열에 맞춰 활용할 수 있습니다.
- 단순 예제가 아니라 생산용 실행 절차에 초점을 둡니다.
