# cmus

`cmus`는 작고 빠른 콘솔 음악 플레이어입니다. ncurses 기반 인터페이스로 로컬 음악 라이브러리를 탐색하고, 곡·앨범·아티스트 기준으로 재생목록을 만들고 관리할 수 있습니다.

## 언제 쓰나

- 콘솔 안에서 음악을 빠르게 찾고 재생하고 싶을 때
- 키보드 중심으로 음악 라이브러리를 관리하고 싶을 때
- 가벼운 Unix용 음악 플레이어가 필요할 때
- 재생목록, 반복, 셔플을 터미널에서 다루고 싶을 때
- GUI 없이 오래 켜 두는 음악 플레이어가 필요할 때

## 핵심 특징

- 빠르고 가벼운 콘솔 UI
- 로컬 라이브러리 중심 재생
- 재생목록과 탐색 기능 지원
- Unix-like 시스템에 잘 맞는 ncurses 플레이어
- 다양한 오디오 플러그인과 백엔드 지원
