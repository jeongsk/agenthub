# MLXcel

MLXcel은 Apple의 MLX 프레임워크를 기반으로 한 실험적 추론 엔진입니다. Rust로 작성되어 Apple Silicon에서 경량화된 모델 추론을 수행합니다.

## 특징

- MLX 기반 경량 추론 엔진
- Rust로 작성된 고성능 구현
- Apple Silicon 최적화
- 실험적 프로젝트 (연구/개발 목적)
