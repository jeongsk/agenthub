# DeepWiki MCP

DeepWiki MCP는 Devin(Cognition)이 제공하는 무료 MCP 서버입니다. GitHub 저장소의 문서를 조회하고, AI 기반으로 저장소에 대한 질문에 답변(Context-grounded response)합니다. 인증 없이 원격으로 바로 사용할 수 있어, 어떤 AI 클라이언트에서든 연결할 수 있습니다.

## 언제 쓰나

- AI 에이전트가 낯선 GitHub 저장소의 문서를 빠르게 조회해야 할 때
- 저장소의 코드를 직접 읽지 않고 AI 기반 요약과 Q&A를 받고 싶을 때
- MCP 클라이언트(Windsurf, Cursor, Claude 등)에서 저장소 지식을 바로 활용하고 싶을 때
- 인증 설정 없이 바로 쓸 수 있는 무료 MCP 서버가 필요할 때

## 특징

- 무료, 인증 불필요, 원격 MCP 서버
- GitHub 저장소 문서 조회 및 AI Q&A 지원
- Windsurf, Cursor, Claude 데스크톱 등 MCP 클라이언트와 호환
- SSE 및 Streamable HTTP 프로토콜 지원
- 공개 저장소 무료 사용, 비공개 저장소는 Devin 계정 필요
