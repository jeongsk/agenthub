# Recordly

Recordly는 화면 녹화와 편집을 한 앱 안에서 처리하는 데스크톱 도구입니다. 자동 줌, 커서 보정, 웹캠 오버레이, 타임라인 편집, MP4/GIF 내보내기를 지원해서 제품 데모나 워크스루 영상을 빠르게 만들 때 유용합니다.

## 언제 쓰나

- 제품 데모나 튜토리얼 영상을 직접 만들고 싶을 때
- 녹화 후 별도 편집 툴로 옮기지 않고 한곳에서 마무리하고 싶을 때
- 자동 줌, 커서 강조, 스타일 프레임으로 영상 품질을 빠르게 올리고 싶을 때
- macOS, Windows, Linux에서 모두 쓸 수 있는 오픈소스 Screen Studio 대안을 찾을 때

## 핵심 특징

- **녹화 + 편집 통합**: 화면 녹화 뒤 바로 타임라인 편집으로 이어집니다.
- **자동 줌과 커서 보정**: 발표나 튜토리얼에 맞는 시각적 강조를 자동으로 더합니다.
- **웹캠 오버레이**: 설명 영상용 얼굴 캠을 유연하게 배치할 수 있습니다.
- **스타일 프레임**: 배경, 그림자, 패딩, 라운드 처리로 완성도를 높입니다.
- **다중 플랫폼**: macOS, Windows, Linux를 지원합니다.
