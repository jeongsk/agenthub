# Rowboat

Rowboat는 이메일, 회의 메모, 캘린더 같은 업무 맥락을 장기 기억 그래프로 쌓아 두고, 그 컨텍스트를 바탕으로 실제 업무를 돕는 로컬 우선 AI 코워커입니다. 회의 준비, 후속 조치, 문서 작성, PDF 덱 생성처럼 이전 맥락이 계속 이어져야 하는 작업에 잘 맞습니다.

![Rowboat AI 코워커 메인 화면](/tool-screenshots/rowboat-ui.webp)

## 언제 쓰나

- 이메일과 회의 메모를 묶어 업무 맥락을 오래 보존하고 싶을 때
- 회의 전 브리핑, 후속 조치, 액션 아이템 정리가 필요할 때
- 문서나 덱을 지금까지의 지식 그래프를 바탕으로 만들고 싶을 때
- 로컬에 남는 Markdown 기반 기억을 직접 보고 편집하고 싶을 때
- MCP나 외부 도구를 붙여 코워커를 확장하고 싶을 때

## 특징

- 로컬 우선 AI 코워커
- Obsidian 호환 Markdown 지식 그래프 저장
- Gmail, Google Calendar, 회의 메모, Fireflies 연동
- 음성 메모와 라이브 노트 지원
- MCP로 외부 도구와 연결 가능
- Mac/Windows/Linux용 다운로드 제공
