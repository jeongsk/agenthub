# Agent Skills Finder

![Agent Skills Finder 홈 화면](/tool-screenshots/agent-skills-finder.png)

Agent Skills Finder는 에이전트용 스킬을 모아둔 검색·큐레이션 디렉터리입니다. 스킬을 워크플로, 문제, 작성자, 카테고리, 설명 기준으로 탐색하고, 컬렉션으로 묶고, 설치 전에 충분히 비교할 수 있게 돕습니다.

## 언제 쓰나

- Claude Code, Codex, OpenClaw용 스킬을 한곳에서 비교하고 싶을 때
- 이미 설치할 스킬이 많아서, 먼저 shortlist를 만들고 싶을 때
- favorites나 컬렉션 기준으로 재사용 가능한 스킬 묶음을 정리하고 싶을 때
- 카테고리와 태그를 기준으로 맞는 스킬을 빠르게 찾고 싶을 때

## 핵심 특징

- **검색 중심**: 워크플로, 문제, 작성자, 카테고리, 설명으로 스킬을 찾습니다.
- **컬렉션 관리**: 여러 스킬을 모아 재사용 가능한 묶음으로 정리합니다.
- **원클릭 설치 흐름**: 상세 페이지와 컬렉션에서 바로 설치 흐름을 이어갑니다.
- **다중 에이전트 지원**: Claude Code, Codex, OpenClaw 등 여러 에이전트 탭을 제공합니다.
- **카테고리 탐색**: UI Design, Frontend Development, Workflow Automation 같은 실제 작업 기준으로 둘러볼 수 있습니다.
