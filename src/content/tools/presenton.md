# Presenton

오픈소스 AI 프레젠테이션 생성기입니다. AI 에이전트가 API를 통해 슬라이드 덱을 자동으로 만들 수 있게 해주며, Gamma, Beautiful AI, Decktopus의 오픈소스 대안 역할을 합니다.

## 언제 쓰나

- AI 에이전트가 회의 자료나 보고서용 슬라이드를 자동 생성하게 하고 싶을 때
- 반복적인 프레젠테이션 제작을 자동화하고 싶을 때
- Gamma, Beautiful AI 같은 서비스의 오픈소스 대안이 필요할 때
- API 기반으로 슬라이드 생성을 워크플로에 통합하고 싶을 때

## 특징

- AI 기반 슬라이드 덱 자동 생성
- REST API로 에이전트/워크플로 연동 가능
- 파워포인트 포맷 출력 지원
- 오픈소스 (셀프 호스팅 가능)
- Gamma/Beautiful AI/Decktopus 대안
