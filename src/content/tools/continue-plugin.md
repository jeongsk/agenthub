# Continue

Continue는 에디터 안에서 코드 맥락을 유지한 채 질문, 수정, 리팩터링을 반복할 수 있게 해 주는 오픈소스 플러그인입니다.

## 핵심 용도

- 코드 질문과 설명
- 리팩터링 보조
- 파일 간 컨텍스트 유지
- 팀 단위 코드 작업 흐름 보강
