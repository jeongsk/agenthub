# LinearMouse

LinearMouse는 macOS에서 마우스와 트랙패드의 동작을 세밀하게 조정할 수 있게 해주는 무료 오픈소스 데스크톱 앱입니다. 기기별, 앱별, 디스플레이별로 프로필을 만들어 스크롤 방향·포인터 속도·가속도·버튼 동작을 각각 다르게 설정할 수 있어서, 트랙패드와 마우스를 함께 쓰는 Mac 사용자에게 특히 맞습니다.

## 언제 쓰나

- 트랙패드는 내츄럴 스크롤을 쓰면서 마우스는 반대로 설정하고 싶을 때
- 마우스마다 포인터 속도와 가속도를 다르게 쓰고 싶을 때
- 특정 앱(예: 포토샵, 일러스트레이터)에서만 마우스 버튼 동작을 바꾸고 싶을 때
- 외장 모니터에 연결했을 때와 내장 디스플레이만 쓸 때의 포인터 설정을 다르게 하고 싶을 때
- 마우스 가속도를 완전히 끄고 일정한 포인터 속도를 유지하고 싶을 때
- 마우스 추가 버튼이나 스크롤 제스처에 단축키/미디어 컨트롤/Mission Control을 할당하고 싶을 때

## 주요 기능

- **프로필** — 기기·앱·디스플레이별로 독립 설정. 연결된 주변기기나 실행 중인 앱에 따라 자동 전환
- **스크롤 커스터마이징** — 방향 반전, 가로/세로 스크롤 각각 독립 설정, 부드러운 스크롤 속도 조절
- **포인터 제어** — 가속도(Acceleration) 세밀 조정, 시스템 기본값 복원, 완전 비활성화
- **버튼 리매핑** — 마우스 추가 버튼, 스크롤 동작을 단축키·미디어·Mission Control·제스처로 재할당
- **경량** — 메뉴바에서 조용히 동작, 시스템 부하 거의 없음

## 설치

```bash
brew install --cask linearmouse
```
