# Hermes Desktop

Hermes Desktop은 Hermes Agent를 위한 데스크톱 동반 앱입니다. 설치와 초기 설정부터 채팅, 세션, 프로필, 메모리, 스킬, 도구, 스케줄, 게이트웨이까지 한 화면에서 관리할 수 있어서, CLI를 직접 만지기보다 GUI로 운영하고 싶은 사용자에게 맞습니다.

## 언제 쓰나

- Hermes Agent를 처음 설치하고 설정하는 과정을 GUI로 따라가고 싶을 때
- 여러 프로필과 모델 설정을 바꿔가며 운영하고 싶을 때
- 세션, 메모리, 스킬, 도구를 화면에서 관리하고 싶을 때
- Telegram, Discord 같은 게이트웨이와 스케줄 기능을 함께 다루고 싶을 때
- 로컬 또는 원격 Hermes 백엔드를 앱으로 붙여 쓰고 싶을 때

## 특징

- Hermes Agent 전용 데스크톱 GUI
- 채팅, 세션 검색, 프로필 전환, 메모리 관리
- 스킬, 도구, 모델, 스케줄, 게이트웨이 관리
- 로컬 또는 원격 백엔드 지원
- Windows, macOS, Linux 지원
- Hermes의 설치와 일상 사용 흐름을 한곳에 모음
