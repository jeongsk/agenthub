# Keymate

Keymate는 휴대폰을 컴퓨터의 컨트롤 패드로 만들어 주는 생산성 도구입니다. Mac/Windows에 데스크톱 앱을 설치하고 iPhone/Android에서 컨트롤러 앱으로 연결하면, 단축키, 텍스트 입력, 앱 실행, 미디어 제어, OBS 방송 제어를 휴대폰 화면에서 바로 할 수 있습니다.

## 언제 쓰나

- 키보드 단축키를 외우기보다 휴대폰 화면에서 버튼으로 실행하고 싶을 때
- 자주 쓰는 텍스트(이메일 주소, 코드 스니펫 등)를 휴대폰에서 컴퓨터로 바로 입력하고 싶을 때
- 방송/녹화 중에 OBS 씬 전환이나 송출 제어를 휴대폰으로 하고 싶을 때
- 앱 실행/음악 재생/볼륨 제어를 손에 든 기기에서 편리하게 조작하고 싶을 때

## 특징

- **크로스 플랫폼**: iPhone + Android + Mac + Windows 모두 지원
- **단축키 실행**: 자주 쓰는 단축키(Copy, Paste, Screenshot, Undo 등)를 버튼 하나로 실행
- **텍스트 입력**: 휴대폰에서 입력한 텍스트를 컴퓨터로 바로 전송
- **앱 실행**: Finder, 파일 탐색기, 브라우저, 음악 앱 등을 원격 실행
- **미디어 제어**: 재생/일시정지, 볼륨, 밝기 조절
- **OBS 방송 제어**: 씬 전환, 녹화 시작/종료, 송출 제어, 음소거
- **Apple Shortcuts 연동**: 애플 단축어와 연결해 커스텀 워크플로우 실행
