# Understand Anything

"그래프는 감동보다 가르침에 쓰는 것"이라는 철학으로 만든 코드 지식 그래프 도구입니다. 코드베이스를 대화형 지식 그래프로 변환해, AI 에이전트가 구조와 관계를 깊이 이해하고 질문할 수 있게 해줍니다.

## 언제 쓰나

- 낯선 코드베이스를 빠르게 파악해야 할 때
- 코드의 구조적 관계(의존성, 호출 흐름 등)를 시각적으로 이해하고 싶을 때
- AI 에이전트가 코드베이스에 대해 질문하고 탐색하게 하고 싶을 때
- 기존 코드 분석 도구보다 더 직관적인 인터페이스가 필요할 때

## 특징

- 코드를 대화형 지식 그래프로 변환
- 탐색, 검색, 질의 응답 지원
- Claude Code, Codex, Cursor, Copilot, Gemini CLI 등 주요 에이전트 호환
- 심볼 관계, 호출 구조, 의존성 그래프 시각화
- 대형 저장소에서도 동작
