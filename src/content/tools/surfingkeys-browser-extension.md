# Surfingkeys

Surfingkeys는 키보드만으로 웹 페이지를 빠르게 탐색하고 조작할 수 있게 해 주는 확장입니다.

## 핵심 용도

- 키보드 중심 웹 탐색
- 빠른 링크 이동
- 검색/탭 관리
- 파워유저용 브라우징
