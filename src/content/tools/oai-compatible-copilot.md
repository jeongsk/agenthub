# OAI Compatible Provider for Copilot

OAI Compatible Provider for Copilot는 GitHub Copilot Chat 안에서 OpenAI 호환 API 공급자를 선택해 쓰게 해 주는 VS Code 확장입니다. Copilot Chat을 기존 모델 대신 Ollama나 Anthropic, Gemini 등으로 연결하고 싶을 때 유용합니다.

## 언제 쓰나

- GitHub Copilot Chat에 커스텀 모델을 붙이고 싶을 때
- OpenAI 호환 API를 VS Code에서 바로 쓰고 싶을 때
- Ollama, Anthropic, Gemini 같은 공급자를 Copilot Chat에 연결하고 싶을 때
- 모델별 설정과 키 관리를 VS Code 안에서 처리하고 싶을 때

## 특징

- OpenAI/Ollama/Anthropic/Gemini 공급자를 지원합니다.
- Copilot Chat 모델 선택기에 커스텀 provider를 추가합니다.
- 다중 provider와 모델별 설정을 관리할 수 있습니다.
- VS Code 설정 UI와 상태 표시줄 흐름을 함께 제공합니다.
