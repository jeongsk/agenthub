# Launch Your Agent

Launch Your Agent는 Anthropic이 공개한 Claude Code 스킬 모음입니다. 창업자가 가진 아이디어에서 시작해, 인터뷰로 요구사항을 정리하고 v0를 스코핑한 뒤 실제 Claude Managed Agent로 런칭, 평가, 반복, 스케줄링까지 이어지는 전체 워크플로를 제공합니다.

## 언제 쓰나

- 아이디어만 있고, 그걸 실제로 돌아가는 에이전트로 만들고 싶을 때
- Managed Agent로 처음 런칭하는 워크플로가 막막할 때
- 만든 에이전트를 그레이딩하고 개선하는 사이클이 필요할 때
- 창업/프로토타이핑 단계에서 빠르게 v0를 내고 싶을 때

## 핵심 특징

- 창업자 인터뷰 → 스코핑 → 런칭 → 그레이딩 → 반복의 전 과정을 Claude Code 스킬로 제공합니다.
- 각 단계가 독립적인 스킬로 구성되어 원하는 부분만 골라 쓸 수 있습니다.
- 상대방의 Claude 계정에 Managed Agent로 직접 배포합니다.
- 평가 스킬을 포함해 만든 에이전트의 품질을 실제로 확인하고 개선합니다.
