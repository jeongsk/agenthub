# gstack

gstack은 Y Combinator CEO Garry Tan이 직접 사용하는 Claude Code 도구 모음입니다. 23개의 전문화된 역할(CEO, 디자이너, 엔지니어링 매니저, QA, 릴리스 매니저, 보안 책임자 등)을 슬래시 커맨드로 즉시 실행할 수 있습니다.

## 언제 쓰나

- Claude Code를 구조화된 워크플로로 사용하고 싶을 때
- PR 리뷰, QA, 디자인 리뷰, 배포 등 개발 전 과정을 체계화하고 싶을 때
- /office-hours, /plan-ceo-review, /review, /qa, /ship 같은 커맨드로 생산성을 높이고 싶을 때
- 스타트업 창업자나 기술 리더가 혼자서 팀처럼 일하고 싶을 때

## 특징

- CEO, 엔지니어링 매니저, 디자이너, QA, 릴리스 엔지니어, 보안 책임자 등 23개 전문 역할
- /office-hours, /plan-ceo-review, /review, /qa, /ship 등 강력한 슬래시 커맨드
- MIT 라이선스, 완전 무료
- 30초 설치, Claude Code 한 줄 커맨드로 셋업 완료
