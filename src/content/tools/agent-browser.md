# Agent Browser

Agent Browser는 Vercel Labs가 만든 AI 에이전트 전용 브라우저 자동화 CLI입니다. Rust로 작성되어 빠르고 가벼우며, AI 에이전트가 웹 페이지를 탐색하고, 폼을 채우고, 콘텐츠를 추출하는 등 브라우저 기반 작업을 수행할 수 있게 해줍니다.

## 언제 쓰나

- AI 에이전트가 웹 페이지를 직접 방문하고 상호작용하게 하고 싶을 때
- Selenium/Puppeteer보다 가볍고 에이전트 친화적인 브라우저 도구가 필요할 때
- Vercel 생태계와 함께 사용할 브라우저 자동화 도구가 필요할 때

## 특징

- Rust 기반 초고속 실행
- AI 에이전트 친화적인 CLI 인터페이스
- 웹 페이지 탐색, 폼 입력, 콘텐츠 추출 지원
- Vercel Labs 제작, 오픈소스
- 34,000+ 스타의 검증된 프로젝트
