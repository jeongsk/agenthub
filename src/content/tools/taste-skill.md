# Taste Skill

Taste Skill은 AI가 만든 화면을 더 보기 좋고 균형 있게 다듬는 데 초점을 둔 프런트엔드 스킬 묶음입니다. 보일러플레이트 같은 화면 대신, 레이아웃·타이포그래피·간격·모션이 살아 있는 결과물을 만들고 싶을 때 유용합니다.

## 언제 쓰나

- AI가 만든 UI가 밋밋하거나 평범해 보일 때
- 랜딩 페이지, 대시보드, 마케팅 화면의 완성도를 끌어올리고 싶을 때
- 디자인 감각이 필요한 프롬프트 규칙을 팀에 공통 적용하고 싶을 때
- Codex, Cursor, Claude Code 같은 에이전트의 프런트엔드 결과물을 개선하고 싶을 때

## 핵심 특징

- **프런트엔드 감각 중심**: 레이아웃과 시각 계층을 더 정교하게 만듭니다.
- **AI 빌드 화면 개선**: “AI가 만든 티”를 줄이고 제품 느낌을 강화합니다.
- **여러 스킬 포함**: 코드 스킬과 이미지 생성 스킬을 함께 제공합니다.
- **웹사이트 동반**: changelog와 설치 안내를 별도 사이트에서 확인할 수 있습니다.
