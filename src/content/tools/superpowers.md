# Superpowers

Superpowers는 AI 에이전트가 뛰어난 개발자처럼 행동하게 만드는 에이전틱 스킬 프레임워크이자 소프트웨어 개발 방법론입니다. 단순한 프롬프트 모음이 아니라, 에이전트가 체계적으로 사고하고 행동하도록 구조화된 접근법을 제공합니다.

## 언제 쓰나

- AI 코딩 에이전트의 일관성과 품질을 높이고 싶을 때
- 에이전트가 프로젝트 전체를 체계적으로 이해하고 작업하게 하고 싶을 때
- 단순 코드 생성 이상의 소프트웨어 개발 방법론을 에이전트에 적용하고 싶을 때
- Claude Code, Codex, Cursor 등 여러 에이전트에서 동일한 워크플로를 사용하고 싶을 때

## 특징

- 에이전트를 위한 구조화된 소프트웨어 개발 방법론
- Claude Code, Codex, Cursor, GitHub Copilot 등 주요 코딩 에이전트 호환
- 20만+ 스타의 대규모 커뮤니티
- 실전에서 검증된 에이전틱 워크플로
- Shell 기반, 설치와 설정이 간단
