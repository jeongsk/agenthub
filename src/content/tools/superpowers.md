# Superpowers

Superpowers는 obra가 만든 에이전틱 스킬 프레임워크이자 소프트웨어 개발 방법론입니다. 233,000개 이상의 GitHub 별을 받은 가장 인기 있는 에이전트 스킬 프로젝트로, 서브에이전트 기반 개발, 브레인스토밍, 코드 리뷰 등 검증된 SDLC 스킬을 제공합니다.

## 언제 쓰나

- 에이전트가 실제로 동작하는 제품을 만들게 하고 싶을 때
- 서브에이전트에게 작업을 위임하고 결과를 종합하는 워크플로가 필요할 때
- SDLC 전 단계(기획·설계·구현·리뷰)를 에이전트가 수행하게 하고 싶을 때
- 브레인스토밍, 코드 리뷰, 스파이크 등 구체적인 엔지니어링 스킬이 필요할 때

## 핵심 특징

- 서브에이전트 기반 개발(Subagent-Driven Development): 복잡한 작업을 여러 에이전트가 병렬로 수행.
- SDLC 전 과정을 커버하는 스킬: 기획, 설계, 구현, 리뷰, 배포.
- 브레인스토밍 스킬로 요구사항 발굴과 아이디어 확장.
- Claude Code, Codex, Cursor, Gemini CLI 등 다양한 에이전트에서 사용 가능.
- 에이전트 간 협업과 결과 종합을 위한 구조화된 방법론.
