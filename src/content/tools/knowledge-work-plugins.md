# Knowledge Work Plugins

Knowledge Work Plugins는 Anthropic이 공개한 역할별 플러그인 저장소입니다. Claude Cowork와 Claude Code에서 업무 역할에 맞는 플러그인을 고르고, 팀별 워크플로와 도구 연결을 빠르게 붙일 때 유용합니다.

## 언제 쓰나

- Claude Cowork 또는 Claude Code에 역할별 플러그인을 추가하고 싶을 때
- 팀 공통의 업무 흐름을 플러그인 형태로 표준화하고 싶을 때
- 커맨드, 스킬, MCP 연결을 한 묶음으로 배포하고 싶을 때
- 공식 저장소를 기준으로 플러그인 구조를 확인하고 싶을 때

## 핵심 특징

- **Anthropic 공식 저장소**: 신뢰할 수 있는 출처에서 플러그인을 확인할 수 있습니다.
- **역할 기반 구성**: 영업, 데이터, 제품 등 업무 역할별 플러그인을 묶어 제공합니다.
- **Claude Cowork/Claude Code 대응**: Cowork와 Claude Code에서 모두 참고할 수 있습니다.
- **플러그인 구조 학습용**: `.claude-plugin`, commands, skills, connectors 구성을 살펴보기 좋습니다.
