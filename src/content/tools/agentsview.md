# agentsview

`agentsview`는 여러 AI 코딩 에이전트의 세션과 비용을 한곳에서 검색·분석하는 로컬 우선 도구입니다. 에이전트별 사용량, 히스토리, 통계가 흩어져 있어서 한 화면으로 모아 보고 싶을 때 유용합니다.

## 언제 쓰나

- Claude Code, Codex, Cursor 등 여러 에이전트의 기록을 한 번에 보고 싶을 때
- 토큰 사용량과 비용 추이를 로컬에서 분석하고 싶을 때
- 세션 히스토리와 검색 가능한 대시보드가 필요할 때
- 계정 연동 없이 자체 저장 데이터만으로 관리하고 싶을 때

## 핵심 특징

- 로컬 우선 설계로 계정 의존도를 낮춥니다.
- 세션 검색, 분석, 통계를 한 화면에서 제공합니다.
- 에이전트별 비용·사용량 추적에 적합합니다.
- 데스크톱/로컬 워크플로에 자연스럽게 들어갑니다.
