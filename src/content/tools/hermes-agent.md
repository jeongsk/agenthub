# Hermes Agent

Hermes Agent는 Nous Research가 만든 AI 에이전트 프레임워크입니다. 900개 이상의 내장 스킬, 150개 이상의 플러그인, 20개 이상의 플랫폼 게이트웨이(Telegram, Discord, Slack 등), 칸반 기반 멀티 에이전트 오케스트레이션을 갖춘 확장 가능한 에이전트 런타임입니다.

## 언제 쓰나

- 다양한 플랫폼(Telegram, Discord, Slack 등)에서 동작하는 AI 에이전트가 필요할 때
- 스킬과 플러그인 시스템으로 에이전트를 확장 가능하게 만들고 싶을 때
- 여러 에이전트를 칸반 보드로 오케스트레이션하고 싶을 때
- 로컬에서 실행되는 오픈소스 에이전트 프레임워크가 필요할 때

## 특징

- 900개 이상의 내장 스킬 (연구, MLOps, 데이터 분석, 생산성 등)
- 150개 이상의 플러그인 (메모리, 모델 제공자, 이미지 생성 등)
- 20개 이상의 플랫폼 게이트웨이 (Telegram, Discord, Slack, WhatsApp, Signal 등)
- 칸반 기반 멀티 에이전트 오케스트레이션
- 크론잡 스케줄러로 자동화 작업 실행
- ACP 프로토콜로 VS Code, Zed, JetBrains 연동
- 다중 모델 제공자 지원 (OpenAI, Anthropic, Google, 로컬 모델 등)
- 활발한 오픈소스 커뮤니티
