# Supertonic

Supertonic는 초고속 온디바이스 다국어 TTS(Text-to-Speech) 엔진입니다. ONNX Runtime을 기반으로 iOS, Web, Android, Node.js, Python, Rust, Go, C++, C#, Flutter, Java, Swift 등 거의 모든 플랫폼에서 네이티브 수준의 음성 합성을 제공합니다.

## 언제 쓰나

- AI 에이전트에 음성 출력 기능을 추가하고 싶을 때
- 온디바이스에서 지연 없이 TTS를 실행하고 싶을 때 (클라우드 불필요)
- 다국어(영어, 한국어, 일본어, 중국어 등) 음성 합성이 필요할 때
- iOS, Web, Android 등 다양한 플랫폼에서 동일한 TTS 엔진을 사용하고 싶을 때

## 특징

- ONNX Runtime 기반 초고속 추론
- 온디바이스 실행 (인터넷/클라우드 불필요)
- 다국어 지원
- 11개 언어/플랫폼 SDK 제공 (Swift, Python, Rust, Go, C++, C#, Java, Flutter, Node.js, Web, iOS)
- WebGPU 가속 지원
- 경량화된 모델로 모바일에서도 실시간 합성
