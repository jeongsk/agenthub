# Learn Quiz

Learn Quiz는 세션 내용을 단계적으로 이해시키기 위한 티칭용 스킬입니다. 인간에게 먼저 이해를 다시 설명하게 만들고, 빈틈을 메운 뒤, 퀴즈로 확인하는 흐름을 강조합니다.

## 언제 쓰나

- 복잡한 변경사항을 상대가 정말 이해했는지 확인하고 싶을 때
- 온보딩이나 리뷰처럼 설명과 확인이 모두 필요한 작업일 때
- “왜 이 변경이 필요한가”부터 차근차근 정리해야 할 때
- open-ended 질문과 선택형 질문을 섞어 이해도를 검증하고 싶을 때

## 핵심 특징

- **단계적 진행**: 한 번에 다 설명하지 않고, 단계별로 이해를 확인합니다.
- **재설명 유도**: 먼저 상대가 스스로 이해를 다시 말하게 만듭니다.
- **퀴즈 기반 검증**: 이해 여부를 질문으로 점검해 빈틈을 줄입니다.
- **맥락 중심**: 문제, 해결, 브로드 컨텍스트를 함께 정리합니다.
