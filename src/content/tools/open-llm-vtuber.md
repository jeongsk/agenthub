# Open-LLM-VTuber

Open-LLM-VTuber는 음성으로 LLM과 대화하고, Live2D 아바타와 함께 반응을 보여 주는 데스크톱 앱입니다. 로컬 실행을 전제로 한 음성 챗봇 워크플로와 VTuber 스타일 데모를 만들 때 잘 맞습니다.

## 언제 쓰나

- 손을 쓰지 않는 음성 대화형 인터페이스가 필요할 때
- LLM 데모를 아바타와 함께 보여 주고 싶을 때
- Live2D와 음성 합성을 결합한 캐릭터형 챗봇을 만들고 싶을 때
- 로컬에서 동작하는 멀티모달 상호작용 앱이 필요할 때

## 핵심 특징

- 음성 입력과 음성 응답을 중심으로 동작합니다.
- Live2D 아바타를 함께 구동해 시각적 반응을 제공합니다.
- 여러 플랫폼에서 로컬 실행을 지원합니다.
- 웹사이트 문서와 Quick Start 가이드가 잘 정리되어 있습니다.
