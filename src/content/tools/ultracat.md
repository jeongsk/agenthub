# UltraCat

UltraCat은 macOS 메뉴 막대 유틸리티입니다. 시스템 상태를 모니터링하고, 팬 제어와 절전 설정을 다룰 수 있습니다.

## 언제 쓰나

- 메뉴 막대에서 시스템 상태를 빠르게 확인하고 싶을 때
- 팬 속도나 절전 관련 동작을 제어해야 할 때
- macOS에서 상시 켜 두는 시스템 유틸리티가 필요할 때

## 특징

- 시스템 모니터링, 팬 제어, 절전 관리를 한 앱에서 제공합니다.
- GitHub Releases로 배포됩니다.
- Sparkle 기반 자동 업데이트를 지원합니다.
- macOS helper 권한이 필요한 기능이 있습니다.

## 참고

- 이 저장소는 에이전트 스킬이나 브라우저 확장보다 **macOS 데스크톱 유틸리티**에 가깝습니다.
- 그래서 이 레지스트리에서는 `desktop-utility`로 분류합니다.
