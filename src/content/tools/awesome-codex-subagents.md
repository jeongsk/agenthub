# Awesome Codex Subagents

Awesome Codex Subagents는 Codex에 바로 붙여 쓸 수 있는 전문 서브에이전트 모음입니다. 개발, 품질, 설계, 보안 등 역할별 에이전트를 카테고리로 정리해 두어서, 필요한 작업 유형에 맞는 에이전트를 빠르게 고르기 좋습니다.

## 언제 쓰나

- Codex용 서브에이전트 구성을 빠르게 참고하고 싶을 때
- 역할별 `.toml` 에이전트를 프로젝트에 맞게 골라 쓰고 싶을 때
- 반복되는 개발 작업을 전용 에이전트로 분리하고 싶을 때
- Codex의 에이전트 디렉터리 구조와 작성 방식을 살펴보고 싶을 때

## 특징

- 160개 이상 Codex 서브에이전트를 카테고리별로 정리
- 개발, 품질, 설계, 보안, 리서치 등 다양한 역할 포함
- Codex 공식 서브에이전트 형식에 맞춘 `.toml` 구성
- 글로벌/프로젝트 단위 설치 흐름을 함께 안내
