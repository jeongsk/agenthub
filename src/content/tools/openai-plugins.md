# OpenAI Plugins

OpenAI Plugins는 Codex 플러그인 예제를 모아 둔 저장소입니다. 플러그인 파일 배치, 명령 정의, 훅, 보조 스킬을 함께 살펴보면서 Codex 워크플로에 맞는 확장 구조를 익히기 좋습니다.

## 언제 쓰나

- Codex용 플러그인 구조를 참고하고 싶을 때
- Figma, Notion, 웹앱, macOS/iOS 같은 작업별 예제를 보고 싶을 때
- 에이전트에 기능 모듈을 붙이는 방식이 궁금할 때
- 팀 내부용 플러그인 템플릿을 설계할 때

## 핵심 특징

- 플러그인별로 독립된 예제 구조를 제공합니다.
- skills, commands, hooks, manifest 등 함께 볼 수 있습니다.
- Codex 중심의 확장 패턴을 빠르게 학습하기 좋습니다.
