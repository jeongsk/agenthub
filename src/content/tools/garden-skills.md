# Garden Skills

ConardLi의 오픈소스 에이전트 스킬 컬렉션입니다. 웹 디자인, 지식 검색(RAG), 이미지 생성(GPT Image 2 API 기반) 등 다양한 영역의 스킬을 포함합니다.

![Garden Skills 웹 디자인 스킬 실행 결과](/tool-screenshots/garden-skills-web-design.webp)

## 언제 쓰나

- AI 에이전트에 웹 디자인 능력을 추가하고 싶을 때
- RAG 기반 지식 검색 스킬이 필요할 때
- GPT Image 2 등 이미지 생성 스킬을 에이전트에 통합하고 싶을 때
- 커뮤니티에서 검증된 다양한 스킬을 한 번에 살펴보고 싶을 때

## 특징

- 웹 디자인, RAG, 이미지 생성 등 다양한 스킬 포함
- CSS 기반 웹 디자인 스킬 특화
- GPT Image 2 API 연동 이미지 생성
- Claude Code 등 주요 에이전트 호환
- 오픈소스 커뮤니티 기여 스킬
