# Vibe-Trading

Vibe-Trading은 개인 맞춤형 트레이딩 AI 에이전트입니다. 다중 에이전트 구조로 시장 분석, 전략 백테스팅, 포트폴리오 관리를 자동화합니다. MCP(Model Context Protocol)를 지원해 Claude Code 등 주요 에이전트와 연동할 수 있습니다.

## 언제 쓰나

- AI 에이전트가 주식/암호화폐 시장을 분석하고 트레이딩 전략을 수립하게 하고 싶을 때
- 백테스팅부터 실시간 모니터링까지 트레이딩 워크플로를 자동화하고 싶을 때
- MCP를 통해 트레이딩 에이전트를 Claude Code 등과 연동하고 싶을 때

## 특징

- 다중 에이전트 구조 (시장 분석, 전략 수립, 리스크 관리)
- 백테스팅 엔진 내장
- MCP 지원으로 외부 에이전트와 연동 가능
- Python 기반, 연구/실전 모두 사용 가능
- 실시간 시장 데이터 처리
