# Anthropic Cybersecurity Skills

754개의 구조화된 사이버보안 스킬을 제공하는 대규모 스킬 팩입니다. 모든 스킬이 5개의 주요 보안 프레임워크(MITRE ATT&CK, NIST CSF 2.0, MITRE ATLAS, D3FEND, NIST AI RMF)에 매핑되어 있어, AI 에이전트가 보안 작업을 수행할 때 일관된 기준을 따르도록 도와줍니다.

## 언제 쓰나

- AI 에이전트에 사이버보안 역량을 추가하고 싶을 때
- 침투 테스트, 위협 탐지, 사고 대응 등 보안 작업을 에이전트가 수행하게 하고 싶을 때
- MITRE ATT&CK, NIST CSF 같은 공식 프레임워크 기반으로 보안 작업을 표준화하고 싶을 때
- 26개 보안 도메인을 아우르는 종합적인 스킬 세트가 필요할 때

## 특징

- 754개 구조화된 사이버보안 스킬 포함
- 5개 프레임워크 매핑 (MITRE ATT&CK, NIST CSF 2.0, MITRE ATLAS, D3FEND, NIST AI RMF)
- 26개 보안 도메인 커버
- agentskills.io 표준 포맷
- Claude Code, GitHub Copilot, Codex CLI, Cursor, Gemini CLI 등 20개 이상 플랫폼 호환
- Apache 2.0 라이선스
