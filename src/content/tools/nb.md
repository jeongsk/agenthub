# nb

`nb`는 CLI와 로컬 웹을 함께 제공하는 노트, 북마크, 아카이브 관리 도구입니다. 평문 저장을 기본으로 하고, Git 기반 버전 관리와 동기화, 태그/필터/검색, 위키식 링크, Pandoc 변환, 암호화 노트까지 지원합니다.

## 언제 쓰나

- 노트와 북마크를 한 도구로 같이 관리하고 싶을 때
- 평문 기반으로 오래 보존 가능한 지식 저장소를 만들고 싶을 때
- Git으로 변경 이력과 동기화를 같이 가져가고 싶을 때
- 로컬 웹 브라우징/검색이 되는 개인 지식베이스가 필요할 때
- Markdown, Org, LaTeX, AsciiDoc 같은 형식 간 변환이 필요할 때

## 핵심 특징

- 평문 중심 저장소
- Git 기반 버전 관리와 동기화
- 태그, 핀, 필터, 검색 지원
- 위키식 링크와 지식 그래프 스타일 연결
- 북마크 아카이빙과 로컬 웹 브라우징
- Pandoc 기반 import/export
- 암호화 노트와 북마크 지원
- Bash 하나로 배포되는 단일 portable script
