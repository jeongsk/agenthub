# Agent Reach

Agent Reach는 에이전트가 공개 웹과 여러 플랫폼 소스를 읽고 검색할 수 있게 해 주는 설치형 도구 모음입니다. 기본 웹 검색을 넘어 소셜 신호와 미디어 자료까지 함께 다루고 싶을 때 유용합니다.

## 언제 쓰나

- 에이전트에게 웹 읽기와 소셜 탐색 능력을 붙이고 싶을 때
- YouTube, Reddit, X, GitHub 같은 소스에서 최신 자료를 모아야 할 때
- 검색과 수집을 로컬 CLI 기반으로 자동화하고 싶을 때
- 여러 채널을 한 번에 설치해 조사 환경을 세팅하고 싶을 때

## 핵심 특징

- 웹, GitHub, YouTube, Reddit, X 등을 한 번에 다룹니다.
- 설치 후 업스트림 도구를 직접 사용하도록 구성됩니다.
- 안전 모드와 드라이런을 지원해 설치 전 확인이 가능합니다.
- 에이전트 중심의 인터넷 접근 레이어로 쓰기 좋습니다.
