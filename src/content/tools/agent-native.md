# Agent Native

Agent Native은 BuilderIO(Qwik, Mitosis 팀)가 만든 에이전트-네이티브 애플리케이션 프레임워크입니다. React 생태계와 긴밀히 통합되어 기존 웹 애플리케이션 위에 AI 에이전트 기능을 레고처럼 쌓을 수 있습니다.

## 언제 쓰나

- 기존 React 앱에 에이전트 기능을 추가하고 싶을 때
- 에이전트와 사람이 같은 UI에서 상호작용하는 앱을 만들고 싶을 때
- BuilderIO/Qsikh 생태계에 익숙한 팀이 빠르게 에이전트 앱을 프로토타이핑할 때

## 핵심 특징

- React/TypeScript 기반 에이전트-네이티브 앱 프레임워크.
- BuilderIO의 컴포넌트 기반 아키텍처 활용.
- 에이전트와 UI 컴포넌트의 자연스러운 통합.
