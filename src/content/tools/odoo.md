# Odoo

Odoo는 비즈니스 운영을 위한 오픈소스 ERP 플랫폼입니다. ERP, CRM, 전자상거래, 회계, 재고 관리, 인사, 마케팅, 제조 등 7만 개 이상의 모듈을 갖춘 종합 비즈니스 관리 시스템입니다.

![Odoo CRM 앱 화면](/tool-screenshots/odoo-erp-dashboard.webp)

## 언제 쓰나

- 비즈니스 운영을 AI 에이전트와 연동하고 싶을 때
- ERP/CRM 데이터를 에이전트가 조회하고 조작하게 하고 싶을 때
- 판매, 재고, 회계 등 비즈니스 프로세스를 자동화하고 싶을 때
- 오픈소스 기반의 종합 비즈니스 플랫폼이 필요할 때

## 특징

- 70,000+ 모듈 (ERP, CRM, 전자상거래, 회계, 재고, 인사, 마케팅, 제조 등)
- Python 기반, 완전 오픈소스
- REST API / XML-RPC로 외부 시스템 및 AI 에이전트 연동 가능
- 웹 기반 UI, 모바일 앱 지원
- 대규모 커뮤니티 및 엔터프라이즈 지원
