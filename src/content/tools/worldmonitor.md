# World Monitor

World Monitor는 전 세계 뉴스, 지정학 동향, 인프라 상태를 실시간으로 추적하는 통합 상황 인식 대시보드입니다. 오픈소스 Palantir 스타일의 지리정치 인텔리전스 플랫폼으로, AI 기반 뉴스 수집과 상황 모니터링을 하나의 화면에서 제공합니다.

## 언제 쓰나

- 전 세계 지정학적 이슈를 실시간으로 추적하고 싶을 때
- AI 기반 뉴스 수집으로 관심 지역/주제의 흐름을 놓치지 않으려 할 때
- 인프라 상태와 지정학 리스크를 함께 모니터링해야 할 때
- OSINT(오픈소스 인텔리전스) 대시보드가 필요할 때

## 핵심 특징

- AI 기반 뉴스 수집 및 요약으로 글로벌 이슈를 빠르게 파악합니다.
- 지정학적 이벤트와 인프라 상태를 통합 뷰에서 모니터링합니다.
- 57,000개 이상의 GitHub 별을 받은 대규모 오픈소스 프로젝트입니다.
- TypeScript 기반으로 웹 브라우저에서 바로 실행됩니다.
- AGPL-3.0 계열 라이선스로 공개되었습니다.
