# Penpot

Penpot은 오픈소스 디자인 및 프로토타이핑 플랫폼입니다. 디자이너와 개발자가 같은 프로젝트에서 실시간으로 협업할 수 있는 Figma의 오픈소스 대안입니다. 웹 브라우저 기반으로 설치 없이 사용할 수 있습니다.

## 언제 쓰나

- 오픈소스 디자인 도구가 필요할 때 (Figma 대안)
- 디자이너와 개발자가 같은 툴에서 협업해야 할 때
- SVG 기반으로 정밀한 UI/UX 디자인과 프로토타이핑을 할 때
- 웹 브라우저에서 바로 디자인을 시작하고 싶을 때

## 핵심 특징

- SVG 기반 벡터 디자인, 웹 브라우저에서 바로 실행.
- 디자이너와 개발자 간 실시간 협업.
- 셀프 호스팅 가능한 오픈소스.
- 컴포넌트 기반 디자인 시스템 지원.
- MPL-2.0 라이선스.
- 50,000개 이상의 GitHub 별.
