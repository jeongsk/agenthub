# AgentMemory

AgentMemory는 AI 코딩 에이전트를 위한 1위 영속적 메모리 시스템입니다. 에이전트가 대화 세션을 넘어 정보를 기억하고, 프로젝트 맥락을 유지하며, 시간이 지나도 학습한 내용을 잊지 않도록 설계되었습니다.

## 언제 쓰나

- AI 에이전트가 이전 세션의 정보를 기억하게 하고 싶을 때
- 대규모 프로젝트에서 에이전트의 컨텍스트 손실 문제를 해결하고 싶을 때
- Claude Code, Codex, Cursor 등 여러 에이전트가 동일한 메모리를 공유하게 하고 싶을 때
- 실제 사용 벤치마크로 검증된 메모리 솔루션이 필요할 때

## 특징

- 실제 벤치마크 기반 설계로 검증된 성능
- Claude Code, Codex, Cursor, Copilot, Hermes Agent, OpenClaw 등 다양한 에이전트 호환
- 영속적 저장으로 세션 간 지식 유지
- TypeScript 기반, npm으로 간단 설치
- Hermes Agent, OpenClaw 등 주요 에이전트 프레임워크와 통합 가능
