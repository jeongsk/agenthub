# DannyMac180 Skills

DannyMac180의 공개 AI 에이전트 스킬 저장소입니다. 현재는 `codex-dynamic-workflows` 한 가지 스킬을 제공하며, 대형 작업을 계획·분해·검증하는 오케스트레이션 흐름을 정리해 둔 것이 특징입니다.

## 언제 쓰나

- 복잡한 작업을 에이전트가 단계적으로 실행하게 하고 싶을 때
- 서브에이전트, 병렬 작업, 검증 단계를 포함한 워크플로를 참고하고 싶을 때
- Codex 스타일의 동적 워크플로 스킬 예시가 필요할 때
- 에이전트용 스킬 패키지를 한곳에서 살펴보고 싶을 때

## 특징

- 공개 AI 에이전트 스킬을 단일 저장소로 정리
- `codex-dynamic-workflows` 기준의 계획/실행/검증 패턴 제공
- 복잡한 작업을 분해해 운영하는 방법을 배우기 좋음
- 스킬 디렉터리를 직접 복사해 설치하는 방식이라 이해가 쉽습니다
