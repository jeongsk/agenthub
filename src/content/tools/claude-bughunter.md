# Claude BugHunter

Claude BugHunter는 Claude Code용 버그 헌팅 스킬 번들입니다. 외부 공격 표면을 중심으로 웹앱·API·인증·클라우드·리포팅 흐름을 구조화해서 다루고 싶을 때 쓰기 좋습니다.

## 언제 쓰나

- Claude Code에 버그 헌팅용 스킬 세트를 바로 붙이고 싶을 때
- 웹앱, API, 인증, 파일 업로드 같은 취약점 탐색 흐름이 필요할 때
- OSINT, 리콘, 증거 정리, 보고서 작성까지 한 번에 정리하고 싶을 때
- 외부 레드팀/버그바운티 작업을 절차화해서 진행하고 싶을 때
- 다양한 vulnerability class별 패턴과 슬래시 커맨드 기반 워크플로가 필요할 때

## 주요 기능

- **51개 스킬** — 버그 헌팅과 외부 레드팀용 전문 스킬 묶음
- **15개 슬래시 커맨드** — 리콘, 헌트, 트리아지, 리포트 흐름 지원
- **681개 리포트 패턴** — 공개 취약점 보고서 패턴을 분류해 활용
- **24개 취약점 클래스** — 웹 취약점 탐색 범위를 넓게 커버
- **증거/리포팅 흐름** — triage, evidence hygiene, report template까지 포함
- **실전 지향 구성** — Claude Code에 자동 로드되는 스킬 시스템 중심
