# kew

`kew`는 터미널에서 동작하는 음악 플레이어입니다. 로컬 음악 라이브러리를 검색해 곡, 앨범, 아티스트 기준으로 재생목록을 만들고, 키보드만으로 탐색·재생·정렬을 이어갈 수 있습니다.

![kew 터미널 음악 플레이어 사용 데모](/tool-screenshots/kew-demo.webp)

## 언제 쓰나

- 터미널 안에서 음악을 빠르게 검색하고 재생하고 싶을 때
- 로컬 음악 라이브러리를 키보드 중심으로 다루고 싶을 때
- 재생목록을 만들고 순서를 바꾸며 들을 때
- 가벼운 CLI 플레이어가 필요할 때
- GUI 없이 음악 감상을 자동화 흐름에 붙이고 싶을 때

## 핵심 특징

- 음악 라이브러리 검색과 자동 재생목록 생성
- 플레이리스트 편집, 셔플, 반복, 즐겨찾기 기능
- 가사, 테마, 시각화, 앨범 커버 지원
- MPRIS 같은 데스크톱 연동 지원
- 터미널 중심의 개인 음악 플레이어
