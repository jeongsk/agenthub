# OpenCut

OpenCut는 웹, 데스크톱, 모바일을 아우르는 오픈소스 비디오 편집기입니다. 현재 저장소는 차세대 코드베이스를 다시 쓰는 중이며, 플러그인 우선 구조, Editor API, MCP 서버, 헤드리스 모드, 스크립팅 탭이 예정되어 있습니다. 영상 편집 도구를 비교하거나 앞으로의 자동화 가능성을 보고 싶을 때 참고하기 좋습니다.

## 언제 쓰나

- 오픈소스 영상 편집기를 찾을 때
- CapCut 대안을 비교할 때
- 웹·데스크톱·모바일을 한 코드베이스로 묶은 편집기 프로젝트를 살펴볼 때
- 향후 플러그인, MCP, 헤드리스 렌더링 지원 여부를 확인하고 싶을 때
- 영상 편집 워크플로를 AI 도구나 자동화와 연결할 가능성을 검토할 때
