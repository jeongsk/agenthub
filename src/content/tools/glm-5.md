# GLM-5

GLM-5는 Z.AI(智谱AI / Zhipu AI)가 공개한 오픈소스 모델 시리즈로, "Vibe Coding에서 에이전틱 엔지니어링으로"라는 비전 아래 장기 과제(long-horizon task)와 에이전틱 코딩에 특화되어 있습니다. GLM-5.2는 1M 토큰 컨텍스트에서 안정적인 성능을 제공하며, Terminal-Bench 2.1에서 오픈소스 모델 중 최고 점수를 기록했습니다.

## 언제 쓰나

- 오픈소스 모델로 에이전틱 코딩 워크플로를 구축할 때
- 장기 실행 과제(long-horizon)에 강한 모델이 필요할 때
- 1M 컨텍스트를 활용한 대규모 코드베이스 작업이 필요할 때
- SWE-bench, Terminal-Bench에서 경쟁력 있는 오픈소스 대안이 필요할 때

## 핵심 특징

- GLM-5.2: 1M 토큰 안정적 컨텍스트, Terminal-Bench 2.1 81.0점 (오픈소스 최고).
- IndexShare 아키텍처로 1M 컨텍스트에서 FLOPs 2.9배 절감.
- 다중 추론 노력 수준(thinking effort levels) 지원.
- SWE-bench Pro, Terminal-Bench, NL2Repo 등 벤치마크 최상위권.
- Apache 2.0 라이선스.
