# OpenStock

OpenStock은 실시간 주가, 알림, 종목 인사이트, 차트를 한곳에서 보여주는 오픈소스 시장 플랫폼입니다. Next.js 기반 웹 앱으로, 비싼 구독형 금융 서비스 대신 무료로 종목을 탐색하고 감시하고 싶은 사용자에게 맞습니다.

![OpenStock 대시보드: 시장 개요, 주가 히트맵, 종목 추적 화면](/tool-screenshots/openstock-dashboard.webp)

## 언제 쓰나

- 특정 종목의 실시간 가격과 흐름을 빠르게 확인하고 싶을 때
- 관심 종목을 watchlist로 모아두고 알림을 받고 싶을 때
- 차트와 회사 정보를 함께 보면서 종목을 비교하고 싶을 때
- 브라우저에서 바로 쓰는 무료 대체 시장 플랫폼이 필요할 때
- 금융 데이터, 뉴스, 차트를 한 화면에서 같이 보고 싶을 때

## 주요 기능

- **실시간 가격 추적** — 종목별 가격 변화를 빠르게 확인
- **개인화 알림** — 원하는 조건에 맞는 알림 설정
- **회사 인사이트** — 종목/기업 상세 정보 탐색
- **차트 통합** — TradingView 위젯 기반 차트와 시장 뷰
- **Watchlist** — 관심 종목을 모아 관리
- **검색/명령 팔레트** — 빠른 종목 탐색과 이동
- **크로스 소스 연동** — Finnhub, MongoDB, Better Auth, Inngest 등으로 구성
