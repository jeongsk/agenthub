# Context7

Upstash가 개발한 Context7은 AI 코드 에디터와 LLM이 항상 최신 상태의 코드 문서를 참조할 수 있게 해주는 MCP 서버입니다. 라이브러리, 프레임워크, API 문서를 실시간으로 조회해 에이전트가 정확한 최신 정보를 바탕으로 코드를 작성할 수 있도록 돕습니다.

## 언제 쓰나

- AI 코딩 에이전트가 최신 API 문서를 참조해 코드를 작성하게 하고 싶을 때
- 라이브러리 버전이 바뀌어도 에이전트가 항상 최신 사용법을 알게 하고 싶을 때
- MCP 서버 형태로 문서 검색 인프라를 에이전트에 붙이고 싶을 때

## 특징

- 라이브러리/프레임워크 문서 실시간 조회
- MCP 프로토콜 기반, 모든 MCP 호환 에이전트에서 사용 가능
- Upstash의 인프라로 안정적인 서비스
- Claude Code, Codex, Cursor, Copilot, Gemini CLI 등 호환
- npx 한 줄로 즉시 실행
