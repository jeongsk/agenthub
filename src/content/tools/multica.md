# Multica

오픈소스 관리형 에이전트 플랫폼입니다. 코딩 에이전트를 단순한 도구가 아닌 진짜 팀원처럼 다룰 수 있게 해줍니다. 작업을 할당하고, 진행 상황을 추적하며, 시간이 지나면서 스킬이 축적되도록 설계되었습니다.

## 언제 쓰나

- 여러 코딩 에이전트를 체계적으로 관리하고 싶을 때
- 에이전트 작업의 진행 상황을 추적하고 싶을 때
- 에이전트가 수행한 작업에서 지식과 스킬이 축적되게 하고 싶을 때
- 단발성 명령이 아닌 지속적인 협업 환경을 구축하고 싶을 때

## 특징

- 작업 할당 및 진행 추적
- 에이전트 스킬 축적 및 관리
- Claude Code, Codex, Cursor, GitHub Copilot 등 주요 코딩 에이전트 지원
- 오픈소스 (셀프 호스팅)
- 팀 협업 중심 설계
