# Claude Code Plugins Directory

Claude Code Plugins Directory는 Anthropic이 관리하는 공식 플러그인 디렉터리입니다. Claude Code에 맞는 플러그인을 찾아 설치하거나, 외부 플러그인을 검토할 때 기준점으로 쓰기 좋습니다.

## 핵심 포인트

- **공식 디렉터리**: Anthropic이 관리하는 플러그인 모음입니다.
- **설치 흐름이 단순함**: Claude Code의 `/plugin` 시스템과 바로 연결됩니다.
- **내부/외부 구분**: Anthropic 내부 플러그인과 파트너/커뮤니티 플러그인을 함께 다룹니다.
- **안전성 참고용**: 설치 전 플러그인 출처와 포함 MCP 서버를 확인하는 출발점이 됩니다.

## 이런 경우에 유용합니다

- Claude Code에 새 플러그인을 추가하고 싶을 때
- 공식 소스에서 어떤 플러그인이 있는지 확인하고 싶을 때
- 플러그인 설치 방식과 디렉터리 구조를 빠르게 파악하고 싶을 때
- 팀에서 Claude Code 플러그인 허용 기준을 정리할 때

## 참고

- 이 저장소는 개별 플러그인 하나가 아니라 *플러그인 디렉터리*입니다.
- 그래서 이 레지스트리에서는 `plugin`으로 분류하는 편이 자연스럽습니다.
