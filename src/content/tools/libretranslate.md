# LibreTranslate

LibreTranslate는 Google·Azure 같은 상용 번역 API 없이 번역 기능을 붙일 수 있는 셀프호스트 번역 서버입니다. 외부 번역 서비스 의존을 줄이고 싶을 때 적합합니다.

![LibreTranslate 번역 화면 예시](/tool-screenshots/libretranslate-translation.png)

## 언제 쓰나

- 번역 API를 직접 호스팅하고 싶을 때
- 오프라인이나 사내망 환경에서 번역이 필요할 때
- 앱이나 워크플로에 다국어 번역 기능을 붙이고 싶을 때
- 상용 번역 API 의존을 줄이고 싶을 때

## 특징

- 번역 API를 제공하는 오픈소스 서버입니다.
- 셀프호스트와 오프라인 사용에 적합합니다.
- Argos Translate 기반이라 로컬/자체 인프라에 얹기 쉽습니다.
- 웹앱, 백엔드, 에이전트 파이프라인에 번역 계층으로 붙이기 좋습니다.
