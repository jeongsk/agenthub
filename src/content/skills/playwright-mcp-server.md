# Playwright MCP Server

Playwright MCP Server는 실제 브라우저를 조작해 웹 흐름을 검증하고 자동화하는 데 유용합니다.

## 핵심 용도

- 로그인/폼 제출
- 스크린샷 기반 검증
- 웹 UI 회귀 테스트
- 브라우저 작업 재현
