# Automa

Automa는 브라우저 작업을 블록 기반 워크플로로 묶어 반복 작업을 줄이는 데 적합합니다.

## 핵심 용도

- 반복 클릭/입력 자동화
- 여러 페이지를 오가는 폼 작업
- 브라우저 기반 RPA
- 수동 작업의 절차화
