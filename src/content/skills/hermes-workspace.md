# Hermes Workspace

Hermes Workspace는 Hermes Agent를 위한 웹 기반 작업 공간입니다. 채팅, 파일, 메모리, 스킬, 터미널, 대시보드를 한 화면에서 다룹니다.

## 언제 쓰나

- Hermes Agent를 위한 통합 작업 공간이 필요할 때
- 채팅, 파일, 메모리, 스킬, 터미널을 한 인터페이스에서 묶고 싶을 때
- 작업 보드나 운영 대시보드 형태의 에이전트 UI를 찾을 때
- 여러 런타임과 워크플로를 오가는 에이전트 운영 환경이 필요할 때

## 특징

- 채팅, 메모리, 스킬, MCP, 파일, 터미널을 통합합니다.
- 대시보드와 Conductor, Agent View, Swarm Mode를 제공합니다.
- Docker 또는 one-line install로 빠르게 시작할 수 있습니다.
- Hermes Agent vanilla parity와 zero-fork 흐름을 강조합니다.

## 참고

- 이 저장소는 단일 기능 도구보다 **에이전트 작업 공간/하네스**에 가깝습니다.
- 그래서 이 레지스트리에서는 `agent-harness`로 분류하는 편이 자연스럽습니다.
