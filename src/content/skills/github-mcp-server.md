# GitHub MCP Server

GitHub MCP Server는 저장소, 이슈, PR, 코드 검색을 에이전트가 직접 다루도록 해 줍니다.

## 핵심 용도

- PR과 이슈 triage
- 저장소 메타데이터 확인
- 코드 위치 검색
- GitHub 기반 운영 자동화
